プライバシーポリシー

最終更新日: 2026年11月5日

Tasks Sync for Rainmeter（以下「本スキン」）は、Windows 用デスクトップカスタマイズツール Rainmeter のスキンです。本スキンは利用者の PC 上だけで動作し、作者はサーバーを運営していません。

取得する情報

本スキンは Google Tasks API（スコープ: https://www.googleapis.com/auth/tasks）を使い、利用者が許可した Google アカウントのタスクリストとタスク（タイトル、期限、完了状態、並び順など）を読み取り・作成・更新・削除します。

情報の使い方

  • 取得した情報は、利用者のデスクトップにタスクを表示し、利用者の操作（完了・追加・編集・削除・リスト切り替え）を Google Tasks に反映するためだけに使います。
  • データは利用者の PC と Google の間で直接やり取りされます。作者や第三者のサーバーへは一切送信しません。
  • 広告、分析、AI の学習、販売、その他の目的には使用しません。

保存する情報

  • ログイン状態を保つためのリフレッシュトークンを、利用者の PC 上に Windows DPAPI で暗号化して保存します（同じ PC の同じ Windows ユーザーのみ復号可能）。
  • 表示用に、現在のリストのタスク内容を利用者の PC 上の Rainmeter 設定ファイルに一時的に書き出します。
  • これらはすべて利用者の PC の %APPDATA%\Rainmeter\TasksSync フォルダに保存されます。

Google API サービスのユーザーデータに関するポリシー

本スキンによる Google API から受け取った情報の使用および他のアプリへの転送は、限定的使用の要件を含む Google API サービスのユーザーデータに関するポリシーを遵守します。

アクセスの取り消し

Google アカウントのアクセス権の管理から本スキンのアクセスをいつでも取り消せます。PC 上のデータは、%APPDATA%\Rainmeter\TasksSync フォルダを削除すると消去されます。

Privacy Policy (English)

Last updated: November 5, 2026

Tasks Sync for Rainmeter ("the skin") is a skin for Rainmeter, a desktop customization tool for Windows. It runs only on the user's PC. The author operates no servers.

Data accessed

The skin uses the Google Tasks API (scope https://www.googleapis.com/auth/tasks) to read, create, update and delete the task lists and tasks (title, due date, status, order) of the Google account the user authorizes.

How data is used

  • Data is used only to display the user's tasks on their desktop and to apply the user's own actions (complete, add, edit, delete, switch list) to Google Tasks.
  • Data travels directly between the user's PC and Google. Nothing is sent to the author or any third party.
  • Data is never used for advertising, analytics, AI training, or sold.

Data stored

  • A refresh token is stored on the user's PC, encrypted with Windows DPAPI (decryptable only by the same Windows user on the same PC).
  • The tasks of the current list are written to local Rainmeter files for display.
  • All of it is stored in %APPDATA%\Rainmeter\TasksSync on the user's PC.

Google API Services User Data Policy

The skin's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

You can revoke access at any time at Google Account permissions. Delete %APPDATA%\Rainmeter\TasksSync to erase local data.
