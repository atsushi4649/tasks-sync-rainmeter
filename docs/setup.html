セットアップ（最初の 1 回だけ・約 10 分）

このスキンは、あなた自身の Google Cloud「OAuth クライアント」を使って、あなたの Google Tasks にアクセスします。データはあなたの PC と Google の間だけでやり取りされます。

必要なもの: 個人の Google（Gmail）アカウント。無料で、クレジットカードの登録も不要です。
会社・学校のアカウントは、管理者が Google Cloud を使えないようにしている場合があります。

Google の画面は時期によって表記が変わることがあります。下のリンクから直接開くのが確実です。

1. プロジェクトを作る

  1. プロジェクトの作成を開く（Google アカウントでログイン）
    • 初めての場合は、国の選択と利用規約への同意を求められます
  2. プロジェクト名: rainmeter-tasks など好きな名前
  3. 場所（組織）: 「組織なし」のままで OK
  4. 「作成」を押し、画面上部でそのプロジェクトが選ばれていることを確認

2. Google Tasks API を有効にする

  1. Google Tasks API を開いて「有効にする」

3. OAuth 同意画面を設定する

  1. OAuth 同意画面を開いて「開始」
  2. アプリ名: Tasks Sync、ユーザーサポートメール: 自分のアドレス
  3. 対象: 外部
  4. 連絡先情報: 自分のアドレス →「次へ」
  5. 終了:「Google API サービス: ユーザーデータに関するポリシーに同意します」にチェックを入れて「続行」→「作成」
    • Google の API を使うアプリの作り手としての決まりごとに同意する項目です。自分で使うだけなら、特に気にすることはありません

ロゴはアップロードしないでください（Google の審査が必要になります）。

4. アプリを「本番環境」にする

作ったアプリは最初「テスト中」で、そのままではログインできません。本番環境に切り替えます（自分専用なので Google の審査は不要です）。

  1. ブランディングを開き、次の 3 つを入力して「保存」
    • アプリケーションのホームページ: https://atsushi4649.github.io/tasks-sync-rainmeter/
    • アプリケーション プライバシー ポリシー リンク: https://atsushi4649.github.io/tasks-sync-rainmeter/privacy.html
    • 承認済みドメイン（「+ ドメインの追加」）: atsushi4649.github.io
  2. 対象を開き、「アプリを公開」→「確認」
  3. 公開ステータスが「本番環境」になれば OK

5. OAuth クライアントを作る

  1. 認証情報を開き、「認証情報を作成」→「OAuth クライアント ID」（新しい画面では「クライアント」→「クライアントを作成」）
  2. アプリケーションの種類: デスクトップ アプリ → 「作成」
  3. 「JSON をダウンロード」（client_secret_〜.json がダウンロード フォルダに保存されます）

6. ログイン

  1. スキン右上の ⟳（同期ボタン）を押す → ダウンロード フォルダの JSON が自動で読み込まれ、「クリックして Google にログイン」に変わります
  2. クリック → ブラウザで許可
  3. 「Google はこのアプリを確認していません」と出たら「続行」（または「詳細」→「安全ではないページに移動」）。自分で作ったアプリなので問題ありません
  4. タスクが表示されたら完了です 🎉

困ったとき

  • 「アクセスをブロック」「403: access_denied」 … アプリが「テスト中」のままです。手順 4 で「本番環境」になっているか確認してください
  • 「アプリを公開」が押せない … 手順 4 のブランディングの 3 項目が保存されているか確認してください。どうしても公開できない場合は、「対象」→「テストユーザー」→「+ Add users」で自分のアドレスを追加すればログインできます（この場合は 7 日ごとに再ログインが必要です）
  • JSON が読み込まれない … スキンを右クリック → データフォルダを開く → そこに client_secret_〜.json を置いて ⟳
  • 右上に ! が出る … マウスを乗せるとエラー内容が出ます。Issues で教えてください
  • ログアウトしたい … Google アカウントのアクセス権から取り消し、%APPDATA%\Rainmeter\TasksSync を削除

Setup (one time, ~10 min)

The skin uses your own Google Cloud OAuth client. Your data only travels between your PC and Google.

  1. Create a project (e.g. rainmeter-tasks). Location: "No organization" is fine. Make sure it is selected. (A personal Google account works; free, no credit card.)
  2. Enable the Google Tasks API.
  3. Open the OAuth consent screen → Get started → app name Tasks Sync, your email, Audience External, contact email, then check "I agree to the Google API Services: User Data Policy" → Continue → Create. Do not upload a logo.
  4. Switch the app to production: on Branding set Homepage https://atsushi4649.github.io/tasks-sync-rainmeter/, Privacy policy https://atsushi4649.github.io/tasks-sync-rainmeter/privacy.html, authorized domain atsushi4649.github.io → Save. Then on Audience click Publish app. (No review is needed for personal use. While the app is in Testing you get "Error 403: access_denied".)
  5. Credentials → Create credentials → OAuth client ID (or Clients → Create client) → Desktop app → Download JSON.
  6. Press the ⟳ button on the skin (the JSON is picked up from Downloads) → click "Click to sign in to Google" → allow. On "Google hasn't verified this app", choose Continue.

If you can't publish, add your address under Audience → Test users instead (sign-in then expires every 7 days).

Sign out: revoke at Google Account permissions and delete %APPDATA%\Rainmeter\TasksSync.
